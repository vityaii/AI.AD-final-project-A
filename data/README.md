# Синтетические данные
Все записи искусственные, не описывают реальную команду.
CSV в UTF-8; пустая ячейка nullable-поля означает NULL, True/False — boolean (PostgreSQL принимает без учёта регистра).
Записи совпадают с INSERT в ../sql/seed.sql. Загружать нужно только один формат.
Набор детерминирован: 8 пользователей и 120 задач. У исходных задач 1–60 сохранены
id и пары проект/номер; их названия и остальные атрибуты переработаны. Новые задачи имеют id 61–120.
В проектах 1–3 соответственно 54, 38 и 28 задач; проект 4 пуст.
Каталог активно развивается (13 завершено), семестр в работе (13 завершено),
архив близок к завершению (20 завершено). Назначения неравномерны и зависят от команды проекта.
Участник 7 участвует в работе, участник 8 пока без назначений.
Названия относятся к предметной области, приоритет medium встречается чаще;
сроки завершённых задач преимущественно в прошлом, задачи очереди чаще без срока и исполнителя.
12 задач не назначены (11 активных), 14 без срока, 13 без оценки; известных просроченных — 26.
Это выбранный учебный сценарий, а не статистическая модель реальной команды.

Воспроизведение из корня проекта: `.venv/bin/python python/generate_seed.py`.
Генератор использует фиксированный seed 20261112 и формирует CSV и SQL из одного набора.
Для загрузки и проверки обновления выполните `python python/verify_project.py`:
повторный seed.sql в существующей БД приведёт к конфликту ключей.
