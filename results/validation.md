# Фактическая проверка
Выполнено 2026-11-12 на локальном PostgreSQL 17.5, отдельный временный кластер
без TCP, без системной службы, без подключения к БД приложения.

- На двух новых пустых БД успешно выполнены schema.sql, seed.sql, checks.sql, queries.sql.
- Оба запуска: 6 пользователей, 4 проекта, 16 колонок, 60 задач; все строки четырёх CSV сверены с SELECT из PostgreSQL.
- Четыре отрицательных проверки получили ожидаемые SQLSTATE и имена ограничений; изменения откачены.
- Восемь фактических CSV экспортированы Python/psycopg. Результаты второго запуска совпали с первым.
- Три графика построены matplotlib по CSV с проверенными хешами. Пустой проект обозначен «не определена».
- ER Mermaid и SVG описывают все поля четырёх таблиц; SVG прошёл XML-проверку.
- Python-файлы выполнились; версии зависимостей зафиксированы.
- Исходная ветка dev и полный git status не изменились, diff до/после совпадает.
- Независимый Git: main, remote отсутствует, коммитов нет.

[Протокол SQL](execution_log.md), [версия PostgreSQL](postgresql_version.txt),
[хеши выгрузки](manifest.json). Временный сервер после проверки остановлен;
для самостоятельного запуска создайте новую учебную БД по README.
Все три PNG просмотрены: подписи читаемы, значения совпадают с CSV, нулевые назначения и неопределённая доля пустого проекта показаны корректно.
